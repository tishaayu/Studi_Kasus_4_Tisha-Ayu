  1. Tampilkan data produk :
     kode ini digunakan untuk melihat seluruh data yang tersimpan sebelumnya, dengan menggunakan kode "print".

  2. Tambahkan data produk :
     kode ini digunakan untuk menambahkan kategori produk, dengan metode add. User harus menginput jenis kategori produk untuk setelahnya ditambahkan ke data. 

  3. Ubah harga produk :
     kode ini digunakan untuk mengubah harga produk di data sebelumnya, dengan menggunakan metode update. User menginput harga terbaru dan secara otomatis harga akan berubah. 

  4. Hapus kategori produk :
     kode ini digunakan untuk menghapus kategori yang ditambahkan sebelumnya dengan menggunakan metode delete. 

  5. Keluar :
     kode ini digunakan untuk menghentikan segala program dengan menggunakan kode "break".
